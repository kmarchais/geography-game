# Quick start

```sh
bun install --frozen-lockfile
bun run ranking
```

In another terminal:

```sh
bun run dev
```

Open http://localhost:3000/geography-game/, enter a name, and choose **Play**.

Read [README.md](README.md) for controls, tests, browser MCP setup, production builds, and the Android path. Read [the project review](docs/project-review.md) for the audit and architecture decisions.
